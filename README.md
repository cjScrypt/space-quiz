# Orbit — Space Quiz

A standalone, 10-question space exploration quiz built with plain HTML, CSS, and JavaScript.

## Run

Open `index.html` in a web browser. No server, build step, or dependencies are required.

## Features

- Ten multiple-choice questions with progress and score tracking
- Correct and incorrect answer feedback with brief space facts
- Results screen with a score-based emoji reaction and replay
- Responsive, centered layout with light and dark system themes
- Keyboard-focusable answer buttons, visible focus indicators, and screen-reader announcements
